# Security Policy

## Reporting a vulnerability

Submit suspected vulnerabilities through the confidential GitHub Security
Advisory form:

https://github.com/jasonbritton12/Axinom_JSON_Helper/security/advisories/new

Do not share credentials, customer data, unpublished content metadata, or
exploit details through public channels.

Include the affected page or release, browser and operating system, reproduction
steps, expected impact, and any suggested mitigation.
